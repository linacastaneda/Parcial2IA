PROYECTO OVERLEAF - INFORME PARCIAL 2 DE IA

1. En Overleaf: Nuevo proyecto > Subir proyecto > seleccionar Informe_Parcial2_IA_Overleaf.zip.
2. Archivo principal: main.tex. Compilador: pdfLaTeX.
3. Carpetas incluidas:
   codigo/  cinco scripts originales del ZIP del estudiante
   salidas/  cinco salidas originales contrastadas mediante nueva ejecución
   figuras/  seis gráficos construidos a partir de los historiales de salida
4. El informe main.pdf ya está compilado para lectura.
5. Para ejecutar los scripts localmente: python codigo/puntoN_...py.
   PSO requiere instalar NumPy: pip install numpy
6. En el punto 2 A.5 la estrategia elegida de reinicios guiados por memoria
   es una propuesta conceptual: no se implementa ni altera el apartado B.
